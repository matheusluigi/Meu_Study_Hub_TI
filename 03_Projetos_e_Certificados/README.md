# 🧩 Projetos e Certificados

Vitrine do que eu construo e das comprovações que acumulo ao longo do curso.

## 📂 Organização

```
03_Projetos_e_Certificados/
├── Projetos_Academicos/    # Projetos feitos nas disciplinas
├── Projetos_Pessoais/      # Projetos por iniciativa própria
└── Certificados/           # Certificados de cursos e eventos
```

## 📌 Convenções

- **Uma pasta por projeto**, com nome sem espaços nem acentos (ex.: `Portfolio_GitHub_Pages`).
- **Todo projeto tem um `README.md`** com: descrição, tecnologias, como executar e status.
- Certificados em PDF, nomeados como `AAAA-MM_Instituicao_Nome-do-Curso.pdf`.
